# 5P–8P game-select icons

Canonical packed assets live in `assets/textures/texture_tkmk00/texture_menu_{5,6,7,8}p_game`
(Ship OTR texture: 80-byte header + big-endian RGBA16, 64×54).

Source PNGs `5p.png` … `8p.png` are the pixel art used to build those binaries.
Rebuild the OTR files after editing the PNGs (see session history / compositor).
