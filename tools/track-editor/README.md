# MK64 Track Editor

Browser-based custom track authoring for **SpaghettiKart** / this repo’s **8-player** fork.

Exports a standard `.o2r` mod. The same file works on stock SpaghettiKart and the 8-player build — validation warnings can be tuned per target, but export bytes are identical.

## Quick start

```bash
cd tools/track-editor
npm install
npm run dev
```

Open the URL Vite prints (default http://localhost:5173).

1. Optionally drag in your local `mk64.o2r` (from the game build / ExtractAssets) for texture browsing.
2. Edit the top-down spline; set surfaces / boost ramps in the inspector.
3. **Export .o2r** → place the file in the SpaghettiKart `mods/` folder  
   (macOS: `~/Library/Application Support/SpaghettiKart/mods/`).
4. Launch the game → ESC → Debug Mode → select your track (custom tracks sort last).

## Architecture

See the plan in the session docs. Summary:

- **TrackDoc** (`.mk64track.json` conceptually) — authoring source of truth
- **Exporter** — loft → F3DEX XML batches → `data_paths` / `data_track_sections` / `scene.json` → zip
- **Collision** — generated by the game at load time; not exported
- **Textures** — referenced by path from `mk64.o2r` (not copied)
